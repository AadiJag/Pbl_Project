About EcoHarvest

How the model works

A look at the dataset, the three models we trained, and why Random Forest came out on top.

Process

From soil data to recommendation

1. Data Input

You provide 7 parameters: N, P, K (soil nutrients), temperature, humidity, pH and rainfall. These represent the key agronomic factors that determine crop suitability.

2. Feature Scaling

Inputs are standardised using StandardScaler — transforming values to a common scale so the model is not biased by different units (e.g. kg/ha vs °C).

3. Model Prediction

Our champion Random Forest model (99.16% accuracy) classifies the input into one of 22 crop categories using an ensemble of 100 decision trees.

4. Result Delivery

The predicted crop is decoded from the label encoder and returned instantly with a contextual icon and confidence indicator. No page reload needed.

Model Performance

3 models trained — 1 champion selected

We benchmarked Random Forest, Gradient Boosting and SVM on 22,000 samples. The one with highest validation accuracy is saved as the prediction engine.

Champion Model — Active in Production

Random Forest

An ensemble of 100 decision trees, each trained on a random bootstrap sample of the data. Trees vote on the final class — majority wins. This bagging approach dramatically reduces variance and overfitting compared to a single tree.

Dataset

22,000 Samples

7 Features

22 Classes

Grains, legumes, fruits, fibres and beverages — a comprehensive crop taxonomy.

80/20 Split

17,600 training samples, 4,400 validation. Random state fixed at 42 for reproducibility.
